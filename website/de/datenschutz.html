Datenschutzrichtlinie

BigPad verarbeitet Dateien ausschließlich lokal und erhebt keine personenbezogenen Daten.

1. Überblick

BigPad ist eine native Open-Source-Anwendung für Windows. Die Anwendung benötigt weder ein Benutzerkonto noch eine Internetverbindung und enthält keine Werbung, Analyse- oder Trackingdienste.

2. Verarbeitung von Dateien

Dateien, die mit BigPad geöffnet oder bearbeitet werden, verbleiben auf dem Computer des Benutzers. BigPad lädt Dateiinhalte nicht auf externe Server hoch und übermittelt sie nicht an den Entwickler oder Dritte.

3. Lokale Einstellungen

BigPad kann Einstellungen wie Sprache, Farbschema, Schriftart und Schriftgröße lokal im Benutzerprofil speichern. Diese Einstellungen werden nicht übertragen und können durch Entfernen der Anwendungseinstellungen gelöscht werden.

4. Telemetrie und externe Dienste

BigPad verwendet keine Telemetrie, Analysedienste, Werbenetzwerke, Cookies oder Cloud-Synchronisierung. Die Anwendung stellt nicht selbstständig eine Verbindung zu externen Diensten her.

5. Website und Downloads

Diese statische Website setzt keine Cookies und bindet keine Analyse- oder Trackingdienste ein. Beim Aufruf der Website oder beim Download über GitHub können der jeweilige Hostinganbieter und GitHub technische Zugriffsdaten nach ihren eigenen Datenschutzbestimmungen verarbeiten.

6. Kontakt und Änderungen

Fragen zum Datenschutz können über das öffentliche BigPad-Projekt auf GitHub gestellt werden. Diese Richtlinie kann angepasst werden, wenn sich die Anwendung oder ihre Datenverarbeitung ändert.
